# ExamPro School Examination Portal

Complete front-end CBT prototype.

## Included
- Homepage
- Student login
- Admin login
- Admin dashboard
- Create exams
- Dynamic question builder (1–200 questions)
- Exam code validation
- Dynamic CBT
- Countdown timer
- Automatic marking
- Result page
- Admin result summary
- Local browser storage
- Responsive mobile design
